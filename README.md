# चारमाही अंदाजपत्रक — बजेट संकलन फॉर्म

## यात काय आहे
- `index.html`, `style.css`, `config.js`, `app.js` — GitHub Pages वर होस्ट करायची फ्रंटएंड फाईल्स
- `Code.gs` — Google Apps Script बॅकएंड (Google Sheets शी जोडणारा कोड)

## सेटअप — 4 स्टेप्स

### स्टेप 1: Google Drive फोल्डर तयार करा
1. Google Drive मध्ये एक नवीन फोल्डर तयार करा (उदा. "चारमाही बजेट 2026-27").
2. तो फोल्डर उघडा, URL मधून फोल्डर ID कॉपी करा:
   `https://drive.google.com/drive/folders/`**`इथली ID`**

### स्टेप 2: Apps Script बॅकएंड डिप्लॉय करा
1. [script.google.com](https://script.google.com) उघडा → "New Project".
2. डिफॉल्ट कोड डिलीट करून `Code.gs` मधील पूर्ण कोड पेस्ट करा.
3. वरच्या भागातील `FOLDER_ID` च्या जागी स्टेप 1 मधली फोल्डर ID टाका.
4. `USERS_SHEET_ID` आधीच तुमच्या "User Management" शीटच्या ID ने भरलेली आहे — ती शीट तुमच्याच
   Google खात्यात असल्याची खात्री करा (कारण स्क्रिप्ट तुमच्या अकाऊंटने चालते).
5. वरती उजवीकडे **Deploy → New deployment** क्लिक करा.
   - Type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone** (महत्त्वाचे — नाहीतर फॉर्म काम करणार नाही)
6. Deploy दाबा → पहिल्यांदा परवानगी (authorize) मागेल, ती द्या (Drive + Sheets दोन्हीसाठी परवानगी लागेल).
7. मिळालेली **Web app URL** कॉपी करून ठेवा (उदा. `https://script.google.com/macros/s/xxxxx/exec`).

### स्टेप 3: फ्रंटएंडमध्ये URL टाका
`app.js` फाईल उघडून वरच्या भागात:
```js
const API_URL = "PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE";
```
इथे स्टेप 2 मधली URL पेस्ट करा.

### स्टेप 4: GitHub Pages वर होस्ट करा
1. GitHub वर नवीन रिपॉझिटरी तयार करा (उदा. `budget-form-2026-27`).
2. या फोल्डरमधील `index.html`, `style.css`, `config.js`, `app.js` अपलोड करा
   (`Code.gs` GitHub वर टाकायची गरज नाही, ती फक्त Apps Script मध्ये असते).
3. Settings → Pages → Branch: `main` → Save.
4. काही मिनिटांत लिंक मिळेल: `https://<तुमचे-युजरनेम>.github.io/budget-form-2026-27/`
5. हीच लिंक 30 जणांना पाठवा.

## वापर कसा होईल
- आता प्रत्येकाला आधी **लॉगिन** करावे लागेल — युजरनेम म्हणजे **डी.डी.ओ. कोड** (उदा. 5101001898),
  पासवर्ड तुमच्या "User Management" शीटमध्ये दिलेला (उदा. Pass@1234).
- **⚠️ महत्त्वाचे**: तुमच्या आधीच्या "User Management" Google Sheet (ID: 1kPrS2B4...) मधील जुना
  डेटा (User_1...User_6) काढून, त्याऐवजी `ddo_code_.xlsx` मधील रचना तिथे भरा —
  **A: डी.डी.कोड/User Name, B: Password, C: कार्यालयाचे नाव, D: Allow Head, E: Actual Head**
  (F स्तंभ — Type Of Budget — कोडमध्ये वापरला जात नाही, तो फक्त तुमच्या संदर्भासाठी ठेवू शकता).
  एकाच DDO कोडाला एकापेक्षा जास्त Head असतील तर त्याच्या तेवढ्या वेगळ्या ओळी ठेवा (जसे सँपलमध्ये आहे).
- **सामान्य युजर (DDO)** लॉगिन केल्यावर:
  1. आधी **लेखाशीर्ष (Head)** निवडण्यासाठी ड्रॉपडाऊन दिसतो (त्या DDO ला Allow असलेलेच Head दिसतील).
  2. मग **चारमाही बजेट / वार्षिक बजेट** असा दुसरा ड्रॉपडाऊन दिसतो.
  3. "पुढे जा" दाबल्यावर वरती मध्यभागी **कार्यालयाचे नाव**, आणि त्याखाली सध्याचा **Head** व
     **बजेट प्रकार** दिसतो. त्यानंतर विवरणपत्रे भरता येतात.
  - एकाच DDO ने वेगवेगळे Head किंवा वेगवेगळा बजेट प्रकार निवडल्यास त्यांचा डेटा **वेगवेगळा** साठवला
    जातो (एकमेकांत मिसळत नाही) — लॉगआऊट करून पुन्हा लॉगिन करून वेगळा Head/प्रकार निवडल्यास त्या
    संयोजनाचा स्वतंत्र डेटा उघडतो/तयार होतो.
- **Master** लॉगिन केल्यास 👑 डॅशबोर्डवर सर्व DDO + त्यांचे Head + चारमाही/वार्षिक स्थिती (✅/⏳)
  दिसते; कोणत्याही ओळीवरील "पहा" दाबून तो नेमका डेटा उघडता येतो.
  **📊 सर्वांचे एकत्रीकरण करा** दाबल्यास — **एकाच Head + एकाच बजेट प्रकाराचे** सर्व DDO एकत्र
  बेरीज केले जातात (वेगवेगळ्या Head चे आकडे चुकून एकत्र मिसळले जाऊ नयेत म्हणून). प्रत्येक
  Head+प्रकार गटासाठी "Master" स्प्रेडशीटमध्ये स्वतंत्र टॅब तयार होतात
  (उदा. `annex1_H22020271_4M`, `annex1_H22020271_Y`, इ.).

## बेरजेबद्दल (एकूण)
- प्रत्येक ओळीत "प्रत्यक्ष खर्च + संभाव्य खर्च = एकूण खर्च" ही **आडवी बेरीज** आपोआप होते (पहिल्यापासूनच होती).
- आता "एकूण", "एकूण (अ)", "एकूण (ब)", विभागवार उपबेरीज (उदा. Annex 5 मधील प्रत्येक विभागाची
  बेरीज) — या सर्व ठिकाणी **उभी बेरीज** (वरच्या संबंधित ओळींची बेरीज) आपोआप होते व ते सेल आता
  फक्त वाचनीय (राखाडी बॅकग्राऊंड) दिसतील, वेगळे भरावे लागणार नाहीत.
- **Annex 7** मध्ये प्रत्येक ओळीच्या शेवटी 12 महिन्यांची **आडवी बेरीज** ("एकूण" कॉलम) दाखवली जाते,
  आणि तळाशी सर्व 18 उद्दिष्टांची **उभी बेरीज** ("एकूण" ओळ) दाखवली जाते.
- **Annex 3अ** आता एप्रिल ते मार्च असे पूर्ण 12 महिने दाखवते (आधी फक्त 4 होते) — तरीही ही "dynamic"
  शीट असल्याने गरज पडल्यास आणखी ओळी जोडता/काढता येतात.

## महत्त्वाच्या नोंदी
- सर्व 30 युजर्सच्या शीट्स एकाच फोल्डरमध्ये जमा होतील — तुम्हाला त्या उघडून बघता/एकत्रित करता येतील.
- `config.js` मध्ये प्रत्येक Annex चे रकाने (columns/rows) दिलेले आहेत — मूळ एक्सेलमधील काही रकाने
  (उदा. Annex 3, 3a, 6) मध्ये एक्सेल फाईलमध्येच माहिती अपूर्ण/रिकामी असल्याने ते "dynamic" (युजरला
  हवे तितक्या ओळी जोडता येतील असे) ठेवले आहेत. गरज पडल्यास मला मूळ भरलेली एक्सेल फाईल (सँपल एंट्रीसह)
  दिल्यास मी अचूक रकाने बसवून देऊ शकतो.
- सध्या Apps Script "Execute as: Me" ठेवल्याने सर्व शीट्स तुमच्या Google खात्यात तयार होतील (सुरक्षित
  व नियंत्रणात राहते) — युजर्सना Google login करायची गरज नाही, फक्त फॉर्ममधला युजरनेम/पासवर्ड पुरेसा आहे.
- मर्यादा: Annex 4 (योजनेची माहिती) हा टेक्स्ट-फॉर्म असल्याने एकत्रीकरणात Master च्या फॉर्म-व्ह्यूमध्ये
  फक्त पहिल्या युजरची माहिती दिसेल — इतर सर्व युजर्सची Annex 4 माहिती "Master" च्या Google Sheet
  फाईलमधील annex4 टॅबमध्ये (प्रत्येक ओळीत एक युजर) पूर्णपणे उपलब्ध असते, ती Sheet मध्ये उघडून बघता येईल.
  याशिवाय Master डॅशबोर्डवरून "👁 पहा" ने कोणत्याही एका युजरची संपूर्ण Annex 4 माहिती स्वतंत्रपणे बघता येते.
